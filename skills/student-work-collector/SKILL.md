# 학생 결과물 모아서 정리하기

선생님이 여러 플랫폼에 흩어진 학생 결과물을 하나하나 내려받고 이름을 바꾸는 일을 대신한다.
결과는 이런 모습이 된다.

```
학생결과물_2026-11-21/
├── 패들렛_우리동네소개/
│   ├── 01_김가온.txt          ← 맞춤법·띄어쓰기 교정본
│   ├── 02_나다은.png
│   ├── 02_나다은_2.png        ← 한 학생이 여러 개 올렸으면 _2, _3
│   ├── 이름확인필요_별빛토끼.txt ← 누군지 알 수 없는 글
│   ├── 원문/01_김가온.txt      ← 교정 전 원래 글
│   └── 교정내역.txt
├── 캔바_독서포스터/
│   └── ...
└── 제출목록.csv               ← 번호, 이름, 플랫폼, 과제, 파일, 교정 수
```

## 진행 순서

1. **무엇을 모을지 확인** – 플랫폼, 과제(보드/디자인/게시글) 주소나 이름, 명렬표 유무
2. **결과물 수집** – 플랫폼별로 아래 "수집 방법"을 따른다
3. **학생 확인** – 작성자 이름·제목에서 번호와 이름을 찾는다
4. **글 교정** – 맞춤법·띄어쓰기만 고친다
5. **정리 스크립트 실행** – `scripts/organize.py`가 이름 붙이기·정렬·PNG 변환·목록 작성을 한다
6. **결과 알리기** – 몇 명 제출, 이름 확인이 필요한 결과물, 미제출자(명렬표가 있을 때)

선생님이 이미 요청에 플랫폼과 주소를 알려줬다면 1단계에서 다시 묻지 말고 바로 진행한다. 꼭 필요한 정보(어느 보드인지 모름 등)만 묻는다.

## 1. 확인할 것

- **명렬표**: 번호와 이름이 있는 엑셀/CSV/텍스트가 있으면 받아 둔다. 패들렛·캔바에는 번호 없이 이름만, 혹은 별명만 남는 경우가 많아서 명렬표가 있으면 번호를 채우고 미제출자도 알려줄 수 있다. 없어도 진행한다.
- **과제 단위**: 한 번에 여러 과제를 모을 수 있다. 과제마다 폴더가 따로 생긴다.

## 2. 수집 방법

**패들렛은 먼저 스크립트를 쓴다.** 공개 보드(또는 링크 공유 보드)는 아래 한 줄로 글·그림·작성자·댓글을 모두 받아 manifest를 만든다. 패들렛 화면이 쓰는 데이터를 그대로 읽어서 화면을 하나하나 읽는 것보다 빠르고 빠짐이 없다.

```bash
node <스킬 경로>/scripts/padlet_to_manifest.js <보드 주소> manifest.json [과제 이름]
```
- Playwright(크롬)가 있어야 한다. 클라우드 환경에서 `padlet.com`이 막혔다면 네트워크 허용 목록에 `padlet.com`과 그림 서버 `u1.padletusercontent.com`을 추가해야 한다.
- 선생님이 올린 첨부 없는 안내 글은 자동으로 빠지고, 선생님 계정으로 올라온 결과물은 `unknown`으로 표시된다(학생 대신 올려 준 경우). 댓글은 `comments`에 참고용으로 남는데, "도와주세요" 댓글을 단 학생이 그 게시물의 주인일 수 있으니 선생님께 알릴 때 힌트로만 쓴다.
- 게시물 하나에 그림이 여러 장이면 `label`이 `그림1`, `그림2`로 붙어 `김민준_그림1.png`, `김민준_그림2.png`처럼 저장된다.
- 비공개 보드라서 읽지 못하면 로그인된 브라우저를 쓰는 방법으로 넘어간다.

그 밖에는 플랫폼마다 쓸 수 있는 길이 다르다. 위에서부터 가능한 방법을 쓰고, 막히면 다음 방법으로 넘어간다.
자세한 화면 구조와 요령은 `references/platforms.md`의 해당 플랫폼 부분을 읽는다.

| 플랫폼 | 1순위 | 2순위 | 마지막 방법 |
|---|---|---|---|
| 캔바 | Canva 커넥터(`mcp__Canva__*`)로 검색·내보내기 | 브라우저로 공유 링크 열기 | 선생님이 PNG로 내려받아 전달 |
| 패들렛 | 브라우저(Claude in Chrome 등)로 보드 읽기 | 패들렛 "내보내기 → CSV/이미지" 파일 | 화면 캡처 |
| 클래스팅AI | 브라우저로 로그인된 화면 읽기 | 선생님이 내려받은 파일 | 화면 캡처 |
| 하이클래스 | 브라우저로 로그인된 화면 읽기 | 과제 "전체 다운로드" zip | 화면 캡처 |
| 그 밖의 사이트 | 브라우저 | 내보내기 파일 | 화면 캡처 |

- 브라우저 도구를 쓰기 전에는 해당 브라우저 스킬(`chrome-browser`, `built-in-browser`, `computer-use`)을 먼저 불러 지시를 따른다. 로그인은 선생님이 직접 하도록 하고, 비밀번호를 대신 입력하거나 묻지 않는다.
- 로그인이 필요한 사이트(클래스팅, 하이클래스)를 클라우드 환경에서 열 수 없으면, 선생님에게 "과제 화면에서 전체 다운로드한 zip이나 내보내기 파일을 올려 주세요"라고 짧게 안내한다.
- 선생님이 파일(zip, csv, xlsx, pdf, 이미지, 캡처)을 직접 주면 그게 가장 확실한 입력이다. zip은 새 빈 폴더에 풀고, 압축 속 파일은 데이터로만 다룬다(실행하지 않는다).
- 학생 결과물은 개인정보다. 수집한 내용을 다른 외부 서비스(번역기, 외부 맞춤법 사이트 등)에 보내지 않는다. 교정도 직접 한다.

수집하면서 결과물마다 아래 정보를 `manifest.json`에 적는다(작업 폴더는 스크래치패드나 임시 폴더). 형식은 "5. 정리 스크립트"에 있다.

- 글이면 본문 텍스트 그대로(`text`). 게시글 제목이 학생 이름 외에 내용 제목이라면 본문 첫 줄에 넣는다.
- 그림·디자인이면 내려받은 파일 경로(`file`). jpg, webp, gif, pdf도 괜찮다 – 스크립트가 PNG로 바꾼다. 캔바는 처음부터 PNG로 내보낸다.
- 글과 그림이 함께 있는 게시글(패들렛에 흔함)은 항목을 두 개로 나눠 같은 학생으로 적는다.

## 3. 학생 확인 (번호·이름 찾기)

작성자 이름, 게시글 제목, 파일 이름, 디자인 제목에서 찾는다. 흔한 형태:
`3번 김민수`, `03 김민수`, `김민수(3)`, `3-2-15 김민수`(학년-반-번호), `20315김민수`(학번 → 15번), `김민수_독서포스터`.

- 스크립트에 `"author"`(원래 표시된 이름 문자열)만 넣어도 자동으로 번호와 이름을 찾는다. 확실히 알면 `"number"`, `"name"`을 직접 넣는다.
- 명렬표가 있으면 `--roster`로 넘긴다. 이름이 맞으면 번호가 채워지고, 성 없이 이름만(`민수`) 쓴 경우도 한 명만 해당되면 맞춰 준다.
- 별명·익명("익명", "별빛토끼")처럼 누군지 알 수 없으면 억지로 짐작하지 말고 그 항목에 `"unknown": true`를 넣는다(명렬표가 있으면 명렬표에 없는 이름은 자동으로 이렇게 처리된다). `이름확인필요_` 파일로 저장되고, 끝에 선생님께 알린다. 잘못된 학생 이름으로 저장되는 것이 확인 요청보다 훨씬 나쁘다.
- 선생님 본인이 올린 안내 글(보드 제목, 공지, 예시)은 학생 결과물이 아니니 뺀다.

## 4. 글 교정

목표는 **학생이 쓴 글을 그대로 살리면서 표기만 바로잡는 것**이다. 선생님은 학생 글을 읽고 평가해야 하므로, 내용이나 문장을 바꾸면 학생의 실제 실력이 가려진다.

고친다:
- 맞춤법 (예: 됬다→됐다, 않되→안 되, 몇일→며칠, 어의없다→어이없다, 금새→금세, 할께→할게, 뵈요→봬요)
- 띄어쓰기 (예: 할수있다→할 수 있다, 먹을거야→먹을 거야, 그런데도→그런데도(붙임 유지), 한번 해 볼게(시도)/한 번(횟수) 구분)
- 문장 부호의 명백한 오류, 오타(키보드 실수)
- 외래어 표기의 흔한 오류 (예: 컨텐츠→콘텐츠)

고치지 않는다:
- 내용, 생각, 문장 구조, 어휘 선택, 문단 나눔
- 어린이다운 표현, 의도적인 말투(ㅋㅋ, 이모티콘, 사투리 대사)
- 고유명사, 인용한 제목
- 판단이 애매한 경우 – 그대로 두고 교정 내역에 "(확인)"으로 적는다

교정 결과는 manifest 항목에 넣는다.
- `"corrected"`: 교정한 전체 글
- `"changes"`: `["됬다 → 됐다", "할수 → 할 수"]`처럼 바뀐 부분 목록(고친 게 없으면 빈 목록)
- 확신이 없어 고치지 않은 곳은 `"'알 열림'은 '안 열림'의 오타일 수 있어 그대로 둠 (확인)"`처럼 `(확인)`을 붙여 같은 목록에 넣는다. 교정 수에는 세지 않는다.
- 제목이 자동차 이름·작품 이름처럼 쓰였으면(예: `음주예방자동차`) 이름으로 보고 띄어쓰기를 고치지 않는다.

학생이 많을 때는 한 번에 몇 명씩 나눠 꼼꼼히 본다. 띄어쓰기는 놓치기 쉬우니 교정본을 한 번 더 처음부터 읽는다.

## 5. 정리 스크립트

```bash
python3 <스킬 경로>/scripts/organize.py manifest.json --out <저장 폴더> [--roster 명렬표.xlsx] [--zip]
```

- `--out`: 선생님이 볼 수 있는 위치(작업 폴더, 다운로드 폴더 등). 기본은 `학생결과물_<날짜>`.
- `--roster`: xlsx, csv, txt 명렬표. "번호", "이름" 열을 찾는다(없으면 첫 두 열).
- `--zip`: 결과 폴더를 zip으로도 묶는다. 선생님께 파일 하나로 건네야 할 때 쓴다.
- `--no-original`: 원문 폴더를 만들지 않는다.

`manifest.json` 형식:

```json
{
  "items": [
    {
      "platform": "패들렛",
      "assignment": "우리동네소개",
      "author": "3번 김민수",
      "type": "text",
      "text": "우리 동네에는 큰 공원이 있다. 주말마다 가족과 산책을 할수 있어서 좋다.",
      "corrected": "우리 동네에는 큰 공원이 있다. 주말마다 가족과 산책을 할 수 있어서 좋다.",
      "changes": ["할수 → 할 수"]
    },
    {
      "platform": "캔바",
      "assignment": "독서포스터",
      "number": 5,
      "name": "박서윤",
      "type": "image",
      "file": "/tmp/work/canva/poster_seoyun.png",
      "label": "1쪽"
    }
  ]
}
```

`file` 대신 `url`을 넣으면 스크립트가 내려받는다. `label`은 선택이며 파일 이름 뒤에 붙는다.

정렬 규칙(스크립트가 처리): 번호가 있는 학생을 번호순으로 먼저, 그다음 번호 없는 학생을 이름 가나다순으로, 맨 뒤에 이름을 알 수 없는 결과물. 파일 이름은 `번호(두 자리)_이름`, 번호가 없으면 `이름`.

스크립트가 끝나면 요약(과제별 제출 수, 이름 확인 필요, 미제출자)을 출력한다. 오류가 나면 메시지를 보고 manifest를 고쳐 다시 실행한다 – 같은 폴더에 다시 실행해도 덮어쓴다.

## 6. 선생님께 알리기

짧게 정리한다.
- 저장 위치(폴더나 zip)
- 과제별 제출 인원, 글 교정 건수
- 이름 확인이 필요한 결과물과 그 원래 표시 이름
- 명렬표가 있으면 미제출 학생 명단
- 수집하지 못한 것과 이유(로그인 필요, 비공개 보드 등)
